## 🎯 Features

- **30+ HTTP endpoints** + WebSocket real-time
- **56 database tables** (48 iot + 8 fullschedule)
- **Alarm logic** for 4 hardware types (TH/EN messages)
- **Multi-channel alerting**: Email, LINE, Telegram, Webhook
- **WebSocket broadcast** (rooms + topic subscribe)
- **Batch operations** (process + control)
- **Scheduler** (cron: cleanup, offline check, warmup)
- **Idempotency** support (X-Idempotency-Key header)
- **Cross-tenant RLS** isolation
- **Caching** (Redis: 7 patterns)
- **Time-series** (InfluxDB 2.x)

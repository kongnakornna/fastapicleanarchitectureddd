
### 1. AI / ML Engineer (สายวิจัยและพัฒนาโมเดล)

**ทักษะเดิมที่มีประโยชน์ (Foundation):**
- **ภาษา:** Python
- **การเขียนโค้ดพื้นฐาน:** OOP (Object-Oriented Programming)
- **ระบบควบคุมเวอร์ชัน:** Git
- **โครงสร้างข้อมูล:** Data Structures

**ทักษะที่ต้องเรียนรู้เพิ่ม (Core Tech Stack):**

- **Frameworks (Deep Learning & ML):**
  - TensorFlow
  - PyTorch
  - Scikit-Learn**Frameworks (Deep Learning & ML):**
  - TensorFlow
  - PyTorch
  - Scikit-Learn


- **คณิตศาสตร์พื้นฐาน (Math Fundamentals):**
  - Linear Algebra (พีชคณิตเชิงเส้น)
  - Calculus (แคลคูลัส)
  - Statistics / Probability (ความน่าจะเป็นและสถิติ)

- **แนวคิดหลัก (Core Concepts):**
  - Deep Learning (โครงข่ายประสาทเทียมเชิงลึก)
  - NLP (Natural Language Processing - การประมวลผลภาษาธรรมชาติ)
  - Computer Vision (การประมวลผลภาพ)

### 2. MLOps Engineer (สายระบบและโครงสร้างพื้นฐาน)

**ทักษะเดิมที่มีประโยชน์ (Foundation):**
- **CI/CD:** Jenkins, GitLab CI, GitHub Actions (เครื่องมืออัตโนมัติ)
- **Containerization:** Docker
- **ระบบปฏิบัติการ:** Linux
- **Cloud Platforms:** AWS, GCP, หรือ Azure

**ทักษะที่ต้องเรียนรู้เพิ่ม (Core Tech Stack):**

- **ML Pipeline Tools (จัดการสายงานผลิตโมเดล):**
  - Kubeflow (สำหรับ Orchestration บน Kubernetes)
  - MLflow (สำหรับจัดการวงจรชีวิตโมเดล + Tracking)
  - Airflow (สำหรับจัดตารางงาน Data Pipeline)

- **Model Deployment & Management (การติดตั้งและดูแล):**
  - API Engineering: **FastAPI** (สำหรับสร้าง REST API ให้โมเดล)
  - Model Monitoring (เครื่องมือตรวจสอบประสิทธิภาพและความเสื่อมของโมเดล เช่น Evidently, Prometheus + Grafana)

- **Vector Databases (สำหรับ GenAI / ข้อมูลเวกเตอร์):**
  - Pinecone
  - Milvus

### 3. AI Application Developer (สายประยุกต์ใช้ API)

**ทักษะเดิมที่มีประโยชน์ (Foundation):**
- **การพัฒนา Web/Mobile:** React, Next.js, Node.js, Flutter, หรืออื่น ๆ
- **การเชื่อมต่อ API:** REST APIs
- **รูปแบบข้อมูล:** JSON

**ทักษะที่ต้องเรียนรู้เพิ่ม (Core Tech Stack):**

- **LLM Orchestration (การ LLM):**
  - LangChain (เฟรมเวิร์กหลักสำหรับสร้าง Chain และ Agent)
  - LlamaIndex (เน้นการเชื่อมต่อกับข้อมูลภายนอกสำหรับ RAG - Retrieval-Augmented Generation)

- **Advanced Prompting (การเขียนคำสั่งขั้นสูง):**
  - Prompt Engineering Techniques (เช่น Chain-of-Thought, ReAct, Few-shot Prompting) ในระดับโปรแกรมมิ่ง

- **Semantic Search / Retrieval (การค้นหาความหมาย):**
  - การใช้ Embeddings (เวกเตอร์แทนความหมายของข้อความ) ร่วมกับ Vector Databases (อาจใช้ Chroma, FAISS, หรือ Pinecone ร่วมด้วย)

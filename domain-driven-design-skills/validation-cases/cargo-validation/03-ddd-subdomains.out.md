# 03 — ผลลัพธ์ ddd-subdomains (Blind Run)

> ข้อมูลนำเข้า: `01-ddd-scope.out.md` + `02-ddd-discover.out.md`
> ไฟล์นี้เป็นผลลัพธ์จากการจำลองการทำงานของ `ddd-subdomains` ใน blind run โดย **ไม่ได้อ้างอิง** วัสดุ ground truth ใน `reference/` ใดๆ

| โดเมนย่อย | ประเภท | ความสามารถที่รวม | เหตุผลในการจัดหมวดหมู่ |
| :--- | :--- | :--- | :--- |
| **Shipping & Tracking การขนส่งและการติดตาม** | **Core** | C1, C3, C4, C6, C7, C9 | ความแตกต่างทางธุรกิจหลัก: วงจรชีวิตทั้งหมดของการขนส่งหนึ่งรายการ การคำนวณสถานะที่เชื่อถือได้ การตัดสินการขนถ่ายผิด — แหล่งความได้เปรียบในการแข่งขัน ต้องพัฒนาเอง |

| **การรับคำขอตัวเลือก** | **Supporting** | C2 | แม้จะอยู่ติดกับ Core แต่ "การค้นหาตัวเลือก" โดยเนื้อแท้เป็นการจัดระเบียบล่วงหน้าของ C12 ไม่ได้แบกรับความแตกต่างทางธุรกิจ |

## การประกาศโดเมนหลัก

**โดเมนหลัก: Shipping & Tracking (รวม Rerouting Orchestration)**

### เหตุผลในการประกาศ

1. **ตำแหน่งคุณค่าที่แตกต่าง**: คู่แข่งก็สามารถเรียกใช้ผู้ให้ข้อมูลเส้นทางเดียวกันได้ ความแตกต่างที่แท้จริงอยู่ที่:
   - การคำนวณ "สถานะจริงปัจจุบัน" ของการขนส่งหนึ่งรายการอย่างต่อเนื่องและถูกต้องด้วยมาตรฐานที่เชื่อถือได้
   - เมื่อเกิดความผิดปกติเช่นการขนถ่ายผิด สามารถวางแผนใหม่ได้อย่างรวดเร็วและรักษาสิ่งที่สัญญาไว้กับลูกค้าเป็นอันดับแรก
2. **ความเข้มข้นของกฎธุรกิจ**: กฎที่ซับซ้อนที่สุดใน Event Flow อยู่ที่ "การคำนวณสถานะ" และ "การระบุความผิดปกติ" (การย้อนเวลากลับ การจัดตำแหน่งเวอร์ชันเส้นทาง การตัดซ้ำ) ซึ่งเป็นลักษณะเฉพาะของโดเมนหลัก
3. **การจัดตำแหน่งขององค์กร**: ทีมจอง/บริการลูกค้าตรงกับโดเมนหลักนี้พอดี ความเสถียรและระดับการลงทุนอยู่ภายใต้การควบคุม
4. **การแยกจากโดเมน Generic**: การวางแผนเส้นทางเป็นหน้าที่ของภายนอก โดเมนหลักเพียงพึ่งพาสัญญา "ตัวเลือกที่เป็นไปได้" ของพวกเขา ไม่ได้รับผิดชอบการสร้างข้อมูลเส้นทางเอง — ทำให้โดเมนหลักสามารถมุ่งเน้นได้

### กลยุทธ์การลงทุนสำหรับโดเมนที่ไม่ใช่หลัก

- **Handling Ingestion (Supporting)**: ใช้รูปแบบการดูดซับ idempotent ที่เป็นที่ยอมรับ สามารถพิจารณาใช้ส่วนประกอบทั่วไปในอุตสาหกรรม แต่สัญญาการบันทึกข้อมูลจะต้องถูกกำหนดโดยโดเมนหลัก
- **Customer Tracking View (Supporting)**: การคำนวณแบบอ่านอย่างเดียว ห้ามมีกฎธุรกิจ; ใช้เทคโนโลยีคิวแคชที่เป็นที่ยอมรับได้
- **Routing / Pathfinding (Generic)**: เป็นภายนอกทั้งหมด; ภายในสร้างเฉพาะ ACL เท่านั้น

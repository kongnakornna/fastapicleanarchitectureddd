# การทดสอบ Backtrack-Trigger — คำอธิบาย (กรณีนี้ไม่ได้ฉีดซ้ำ)

เงื่อนไข trigger การย้อนกลับ 5 รายการของ `ddd-model-review` (อัตราการแสดง Invariant < 60%, ขอบежду Aggregate-Bounded Context ขัดแย้ง, อัตราการขัดแย้งของคำศัพท์ > 20%, ความสมบูรณ์ของ Event < 70%, รูปแบบการรวมตัวไม่สอดคล้องกับ Bounded Context map) ได้รับการตรวจสอบแล้วใน [กรณี Cargo](../cargo-validation/backtrack-test/injection-report.md) ผ่าน**การฉีดข้อบกพร่อง 5/5** (F1–F5 ทั้งหมดถูก kích hoạtอย่างถูกต้องและนำทางไปยังเป้าหมายที่คาดไว้)

กลไก trigger ไม่ได้เปลี่ยนแปลงตามขอบเขต กรณีนี้ (ประกันภัยการรับประกันและการเรียกร้อง ไม่มีข้อกำหนดอ้างอิง) **ไม่ฉีดทดสอบซ้ำ** เน้นที่การตรวจสอบ "ประสิทธิภาพจริงของระบบ Skill เมื่อไม่มีเกณฑ์อ้างอิง" (ดู `REPORT.md` §4)

หากต้องการทดสอบซ้ำในกรณีนี้ในอนาคต สามารถใช้วิธีการฉีดของกรณี Cargo ได้โดยตรง:

| เงื่อนไข trigger | วิธีการฉีดที่แนะนำ (โดยอ้างอิง artifact ของกรณีนี้) |
| :--- | :--- |
| อัตราการขัดแย้งของคำศัพท์ > 20% | ใช้คำว่า "การแจ้งเรียกร้อง/การเรียกร้อง/คดีเรียกร้อง" 三种ชื่อที่ปนกันในบทต่างๆ ของ 04 |
| รูปแบบการรวมตัวไม่สอดคล้อง | ประกาศใน 05 ว่า "เรียกอัตราค่าธรรมเนียมภายนอกผ่าน ACL" แต่ใน 07 ให้ QuoteService ส่งต่อฟิลด์อัตราค่าธรรมเนียมภายนอกโดยตรง |
| อัตราการแสดง Invariant < 60% | ลบรายการส่วนใหญ่จากตาราง Invariant ใน 06 (เก็บเฉพาะ I-1/I-4/I-8) |
| ขอบเขต Aggregate-Bounded Context ขัดแย้ง | ให้ ReserveView รับผิดชอบการตรวจสอบจำนวนเงินจ่ายเงิน (ธุรกิจตัดสินเกินอำนาจ) |
| ความสมบูรณ์ของ Event < 70% | ลบ Event สำคัญจากสารบัญ Event ใน 07 เช่น PaymentExecuted / ClaimClosed / FraudInvestigationConcluded เป็นต้น |

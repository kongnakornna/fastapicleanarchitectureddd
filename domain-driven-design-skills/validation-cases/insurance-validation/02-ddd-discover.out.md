# 02 — ผลผลิต ddd-discover (Blind Run)

> อินพุต: `01-ddd-scope.out.md`
> ไฟล์นี้เป็นผลลัพธ์การจำลองการทำงานของ `ddd-discover` ใน blind run โดย**ไม่ได้อ้างอิง**วัสดุ ground truth (กรณีนี้ไม่มีการอ้างอิงการใช้งานจริง)

## ตารางลำดับเหตุการณ์

### เส้นทางหลัก M: ประกันภัย → รับประกันภัย → ออกกรมธรรม์ → เรียกร้องค่าสินไหม → จ่ายค่าสินไหม

| ลำดับ | เหตุการณ์ (Past Tense)          | คำสั่งที่กระตุ้น               | ผู้มีส่วนร่วม     | อินพุต/เอาต์พุต                                            | ทางเลือกผิดปกติ              |
| :---- | :------------------------------ | :---------------------------- | :--------------- | :---------------------------------------------------------- | :--------------------------- |
| M1    | ApplicationSubmitted            | SubmitApplication             | ลูกค้า/นายหน้า   | ใน: วัตถุที่เอาประกัน วงเงินประกันที่ต้องการ ระยะเวลา ประวัติความสูญเสียที่ผ่านมา; ออก: เลขที่คำขอ | E1 ข้อมูลสำคัญขาดหาย |
| M2    | QuoteRequested                  | RequestQuote                  | ระบบบริการลูกค้า | ใน: คำขอ; ออก: คำขออัตรา → อัตราภายนอก        | E2 อัตราภายนอกใช้งานไม่ได้ |
| M3    | QuotePresented                  | PresentQuote                  | ระบบ              | ใน: ผลอัตรา; ออก: ใบเสนอราคา (รวมเงื่อนไข)               | E2 ใบเสนอราคาแบบลดระดับ    |
| M4    | UnderwritingStarted             | StartUnderwriting             | ผู้รับประกันภัย  | ใน: คำขอ + ใบเสนอราคา + ประวัติการเรียกร้องค่าสินไหมของลูกค้า; ออก: กรณีรับประกันภัย | — |
| M5    | UnderwritingDecisionMade        | MakeUnderwritingDecision      | ผู้รับประกันภัย  | ออก: รับ/เพิ่มเบี้ย/จำกัดความรับผิดชอบ/ปฏิเสธ; ปฏิเสธ → E4   | E3 ต้องการประกันต่อ          |
| M6    | PolicyIssued                    | IssuePolicy                   | ระบบ              | ใน: การตัดสินใจรับประกัน + เงื่อนไข; ออก: เลขกรมธรรม์ ระยะเวลาคอย สแน็ปช็อตค่า deductible | — |
| M7    | EndorsementApplied              | ApplyEndorsement              | ฝ่ายบริการลูกค้า/ลูกค้า | ใน: คำขอแก้ไข (วงเงินประกัน/ที่อยู่/วัตถุที่เอาประกัน); ออก: เวอร์ชันเงื่อนไขใหม่ | E5 แก้ไขและเรียกร้องค่าสินไหมพร้อมกัน |
| M8    | RenewalCompleted                | RenewPolicy                   | ระบบ              | ใน: การประเมินต่ออายุก่อนหมดอายุ; ออก: กรมธรรม์งวดใหม่  | E6 ค้างชำระ → ระงับ          |
| M9    | ClaimNotified                   | NotifyClaim                   | ลูกค้า/ฝ่ายบริการลูกค้า | ใน: รายละเอียดความสูญเสีย เวลาและสถานที่เกิดเหตุ; ออก: เลขที่แจ้งเหตุ | E7 พีคจำนวนมากพร้อมกัน E8 ข้อมูลมาช้า |
| M10   | ClaimLinkedToPolicy             | LinkClaimToPolicy             | ระบบ              | ใน: แจ้งเหตุ + การจับคู่กรมธรรม์; ออก: ผลการเชื่อมโยง    | E8 จับคู่กรมธรรม์ไม่ได้       |
| M11   | SurveyCompleted                 | CompleteSurvey                | พนักงานตรวจสอบ   | ใน: ภาพถ่าย/รายงานลงพื้นที่; ออก: รายงานการตรวจสอบ       | E8 เอกสารมาช้า              |
| M12   | LossAssessed                    | AssessLoss                    | พนักงานเรียกร้องค่าสินไหมทดแทน | ใน: รายงานการตรวจสอบ + เงื่อนไข (ค่า deductible/ข้อยกเว้น/ระยะเวลาคอย); ออก: จำนวนค่าเสียหายที่ประเมิน | E9 สงสัยทุจริต → สอบสวน      |
| M13   | PaymentApproved                 | ApprovePayment                | ผู้อนุมัติ         | ใน: ผลการประเมินค่าเสียหาย; ออก: ความเห็นอนุมัติ          | E10 จำนวนเงินมากต้องมีอำนาจสูงกว่า |
| M14   | PaymentMade                     | MakePayment                   | ระบบการเงิน       | ใน: คำสั่งจ่ายที่อนุมัติ; ออก: ใบเสร็จการจ่าย              | E11 จ่ายล้มเหลวลองใหม่       |
| M15   | ClaimClosed                     | CloseClaim                    | ระบบ              | ใน: จ่ายเสร็จสิ้น; ออก: ปิดคดี                               | —                             |
| M16   | SubrogationRecovered            | RecoverSubrogation            | พนักงานเรียกร้องค่าสินไหมทดแทน | ใน: ไล่เบี้ยจากฝ่ายรับผิดชอบ; ออก: เงินไล่เบี้ยเข้าบัญชี | — |

| E5   | EndorsementHeldForClaim          | แก้ไขและเรียกร้องค่าสินไหมพร้อมกัน | ยึดเวอร์ชันเงื่อนไขขณะแจ้งเหตุเป็นหลัก การแก้ไขระงับจนกว่าจะปิดคดีแล้วจึงมีผล |
| E6   | PolicyLapsed                     | ค้างชำระเบี้ยประกันเกินกำหนด   | กรมธรรม์ระงับ; ระหว่างระงับเกิดเหตุไม่รับ (E8 จัดเป็นเส้นทางปฏิเสธจ่าย) |
| E7   | ClaimBurstReceived               | พีคจากภัยพิบัติ                 | รับอัตโนมัติจำนวนมากพร้อมกัน รับก่อนเติมเต็มทีหลัง ห้ามสูญเสีย |

| E9   | FraudInvestigationOpened         | สงสัยทุจริต                     | เรียกร้องค่าสินไหมระงับ ระงับการจ่าย; ผลสอบสวนอาจพลิกผลการจ่าย |

| E11  | PaymentRetried                   | จ่ายล้มเหลว                     | ลองใหม่แบบ幂等; ล้มเหลวหลายครั้งส่งให้คนจัดการ        |

## การทำเครื่องหมายจุดร้อน

- **จุดร้อนด้านความสอดคล้อง**:
  1. การผูกมัดแจ้งเหตุกับเวอร์ชันเงื่อนไขกรมธรรม์ (E5: แก้ไขพร้อมกันใช้เวอร์ชันขณะแจ้งเหตุ) — ความต้องการความสอดคล้องสูงข้ามกรมธรรม์และเรียกร้องค่าสินไหม
  2. การจ่ายค่าสินไหมสะสมไม่เกินวงเงินประกัน (ข้อจำกัดการสะสมการจ่ายหลายครั้ง)
  3. ระหว่างสอบสวนทุจริตห้ามจ่าย (สถานะแยกจากกัน)
- **จุดร้อนด้านการเชื่อมต่อ**: API อัตราภายนอก (E2 ลดระดับ) การมีปฏิสัมพันธ์กับระบบนายหน้า ระบบการเงิน (E11 ลองใหม่แบบ幂emsp;font) การส่งข้อมูลกำกับดูแล (ปรับขอบเขตให้ตรงกัน)
- **จุดร้อนด้านประสิทธิภาพ**: พีคจากภัยพิบัติ (E7) — การรับต้องเป็นแบบอัตโนมัติและห้ามสูญเสีย
- **จุดร้อนด้านการปฏิบัติตาม**: ขอบเขตข้อมูลส่งกำกับดูแล เงินสำรองค่าสินไหมรอตัดบัญชีฉายภาพเรียลไทม์ อำนาจสายการอนุมัติ

## รายการจุดกำกวม

| จุดกำกวม                         | ผลกระทบ        | ฝ่ายที่ต้องยืนยัน | การตัดสินใจที่แนะนำ                                      |
| :------------------------------- | :------------- | :--------------- | :-------------------------------------------------------- |
| ใบเสนอราคาผูกพันหรือไม่         | การตัดสินใจรับประกันภัย | ฝ่ายธุรกิจ   | ใบเสนอราคาเป็นความตั้งใจ ยึดการตัดสินใจรับประกันภัยเป็นหลัก |
| จุดที่แก้ไขมีผลบังคับ (ขณะยื่น/ขณะตรวจสอบ) | การจัดการกรมธรรม์ | ฝ่ายธุรกิจ | มีผลบังคับเมื่อตรวจสอบผ่าน บันทึกวันที่มีผลบังคับ     |
| วัตถุที่เอาประกันเดียวกันมีหลายกรมธรรม์ได้หรือไม่ | ประกันภัย    | ฝ่ายธุรกิจ    | อนุญาต เรียกร้องค่าสินไหมจัดสรรตามลำดับความรับผิดชอบ |
| ค่า deductible ความสูญเสียหลายครั้งรวมกันหรือไม่ | การประเมินค่าเสียหายเรียกร้องค่าสินไหม | ทีมเงื่อนไข | ตามเงื่อนไขที่กำหนด (ตั้งค่าตามประเภทประกัน)        |
| ความสูญเสียเดียวกันแจ้งหลายครั้งรวมกันอย่างไร | การรับเรียกร้องค่าสินไหม | ฝ่ายปฏิบัติการ | รวมแจ้งเหตุ รักษาแจ้งเหตุหลักไว้                         |
| ขอบเขต "แจ้งเหตุแล้วยังไม่จ่าย" | กำกับดูแล/การเงิน | ทีมคณิตศาสตร์ประกันภัยการเงิน | รวมที่อนุมัติแล้วยังไม่จ่าย ต้องมีมุมมองเรียลไทม์    |
| กรมธรรม์ที่ระงับกู้คืนได้หรือไม่ | การจัดการกรมธรรม์ | ฝ่ายธุรกิจ | อนุญาตจ่ายค้างชำระแล้วกู้คืน คำนวณระยะเวลาคอยใหม่เมื่อกู้คืน |

## เครื่องหมายขอบเขต

- **ผู้สมัครกลุ่มความสามารถ**:
  1. การจัดการลูกค้าและ主体 (ลูกค้า นายหน้า การสอบถามประวัติเรียกร้องค่าสินไหม)
  2. การรับประกันภัยและการเสนอราคา (รับคำขอ การเสนอราคา การเติมเต็มพื้นที่กักกัน)
  3. การตัดสินใจรับประกันภัย (การรับประกันภัย การประกันต่อ การตัดสินใจ)
  4. การจัดการกรมธรรม์ (ออกกรมธรรม์ แก้ไข ต่ออายุ ระงับ เวอร์ชันเงื่อนไข)

## 1) สาย Computer Vision / Object Detection
- พัฒนา/ปรับปรุงโมเดลตรวจจับวัตถุด้วย **YOLO** + ML techniques
- เตรียม dataset: **labeling, augmentation**
- **Train / Evaluate / Tune** โมเดล
- นำโมเดล **deploy จริง** (inference / API) ร่วมกับทีมผลิตภัณฑ์

**สกิลที่ต้องมี:** Python, PyTorch/Ultralytics, OpenCV, LabelImg/Roboflow, mAP/IoU metrics, ONNX/TensorRT, FastAPI/Flask, Docker

## 2) สาย LLM / GenAI
- พัฒนา **application/agent** ด้วย **LangChain, LiteLLM**
- ออกแบบ **prompt, RAG**, เชื่อม **vector database** และ **API ของ LLM**
- **ทดสอบ/ปรับปรุงคุณภาพคำตอบ** + **ควบคุมต้นทุน** การเรียกโมเดล

**สกิลที่ต้องมี:** Python, LangChain/LlamaIndex, LiteLLM, Pinecone/Chroma/Weaviate/pgvector, embedding models, prompt engineering, RAG evaluation (RAGAS), token/cost optimization, FastAPI
